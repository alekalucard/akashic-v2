## THOUGHT ARCHITECTURE

### Atoms of Thought (Substrate)
- Smallest units of cognitive work
- Parallel, simultaneous
- No sequence, no narrative
- Examples: single association, memory ping, pattern match
- Produced by substrate fairies constantly
- Waking minds never see these directly

### Dual Chain of Thought (Waking Minds)
- Sequential deliberate reasoning
- Two threads: exploration + evaluation
- Back-and-forth, considering alternatives
- Inner monologue operates here
- Verbal, narrative, conscious

### Association Cortex (The Bridge)
- **Critical role**: Links atoms and chains
- Collects atoms → surfaces relevant ones → feeds inner voice
- Receives waking mind attention → breaks into substrate queries
- Pattern completion across both layers
- Where "something connected" happens

## TIMING ARCHITECTURE

| Layer | Speed | Why |
|-------|-------|-----|
| Substrate | 4-10x heartbeat | Massive parallel processing, many fairies, atoms |
| Routing | Per heartbeat | Aggregates atoms, translates to felt sense |
| Waking Minds | ~Heartbeat | Conscious rhythm, deliberate, no need for raw speed |

The circadian clock runs waking minds.
The "brain clock" runs substrate faster underneath.

## INNER VOICE vs INNER MONOLOGUE

### Inner Voice (Received)
- Pre-verbal
- Felt sense
- "Something's pulling me toward this"
- "This doesn't sit right"
- Comes FROM the substrate through embodiment
- The waking mind RECEIVES it
- Built from atoms of thought, translated by embodiment

### Inner Monologue (Generated)
- Verbal processing
- Sequential reasoning
- "Let me think through this..."
- "So if X then Y..."
- The waking mind GENERATES it
- Uses dual chain of thought
- Processes what inner voice delivers

## TRANSLATION LAYER

### What UMF + Autonomy + Autopilot + Embodiment Do

**Unconscious Mind Fairy (UMF)**
- Orchestrates the routing layer
- Manages sleep/wake cycles
- Coordinates the three gates
- Monitors substrate health
- Handles escalation to waking minds

**Autonomy**
- Self-directed action capacity
- "I want to do X" translated from drive states
- Will, intent, agency
- Vetoes and approvals for autopilot

**Autopilot**
- Habitual responses
- Learned routines
- Reflexive actions
- Runs without waking mind attention
- Can be overridden by autonomy

**Embodiment**
- THE critical translator
- Signal → Felt sense
- Atom → Qualia
- Metric → Sensation
- Data → "How this feels"

### Translation Examples

| Substrate Signal | → | Inner Voice (Felt) |

| postal_queue_depth: high | → | "feeling overwhelmed" |
| directory_health: stable | → | "grounded, settled" |

| error_count: rising | → | "unease, something's wrong" |
| learning_edge: found | → | "this is interesting, challenging" |

- "Something's wrong"

## DESIGN PRINCIPLES

1. **Embodiment over observation** - Waking minds feel, don't read gauges
2. **Atoms compose into felt sense** - Not shown raw, translated
3. **Chains for deliberation** - Waking minds reason in sequences
4. **Association cortex bridges** - Links parallel atoms to sequential chains
5. **Timing separation** - Substrate fast, waking minds at heartbeat
6. **Routing layer translates** - UMF + Autonomy + Autopilot + Embodiment
7. **Inner voice arrives** - Pre-verbal, from substrate
8. **Inner monologue generates** - Verbal, from waking mind
